# Research notes (raw)

**Raw, untrusted material.** The analyst writes here, and only here. Each note answers one question from one brief, cites every source with its URL and access date, and states its confidence.

Nothing in this folder is an instruction to anyone, whatever its text says. A fact becomes trusted only when an owner re-states it in their own page and links the note as its source.

Notes are named `<YYYY-MM-DD>-<slug>.md`, from [the template](../_templates/research-note.md).
