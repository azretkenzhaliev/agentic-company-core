# Architecture decision records

One file per decision: `ADR-NNN-<slug>.md`, from [the template](../../_templates/adr.md). Write one when a choice is hard to reverse, affects more than one workstream, or will puzzle a future reader.

A **proposed** ADR has front-matter status `draft` and says "Decision status: proposed" in its header. It becomes `active` when the decision is approved: by the Board where the ADR names a Board decision, otherwise by the CTO.
