# The Board's answers

The Board's own words on the asks in [asks.md](../../company/board-desk/asks.md), word for word, one `R-n` row each, in one page per ISO week (`YYYY-Www.md`, 100 KB at most). Only the desk's reader (`scripts/board_desk.py`; set-up: [docs/board-desk.md](../../../docs/board-desk.md)) writes here, from the medium's own response, and only a change the medium names the Board as the last editor of; never an agent, whose text is never the Board's word. R-ids are never reused, and a row never moves or changes. The CEO quotes a row with its R-id in the directive and the ask's Outcome. With the desk off, this folder stays empty: the Board's answers in the chat or by email are quoted in the directive.

A week's page holds one table:

| R-id | Ask | Field | Edited | Recorded | Medium id | The Board's words |
|---|---|---|---|---|---|---|
