# Directives

One file per Board directive: `D-YYYYMMDD-<slug>.md`, created from [the template](../../_templates/directive.md). The CEO files and updates them. The "Directive (verbatim)" section of each file is the Board's text and is never edited.

**NEXT rows.** A new `NEXT:` row carries every unfinished step of the row it replaces, or says where each went: done (with its source), an order, or dropped (by whom and why). A step that falls out of a `NEXT:` row is a step nobody does.
