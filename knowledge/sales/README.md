# Sales

**Owner: the CEO, acting CSO,** until a CSO agent exists. The CEO's `sales-playbook` skill is the procedure. It's the seed of the future CSO's prompt.

## Layout

One folder per product, created when work on it starts:

| Page | What |
|---|---|
| `<product>/icp.md` | Link to `marketing/<product>/icp.md`; sales-specific qualification criteria |
| `<product>/pricing.md` | Current prices and plans, **as set by the Board**, and proposals |
| `<product>/pipeline.md` | Segments, lead sources, stages, conversion data |
| `<product>/playbook.md` | Discovery questions, objections and answers, demo flow |
| `<product>/outreach/` | Outreach drafts and sequences, `draft` until the Board approves sending |
| `<product>/partners.md` | Partner types, mutual value, approach, what needs Board approval |

## Rules

- **No outreach, offers, discounts, contracts or price changes leave the company without the Board.**
- No personal data about individual leads in the KB unless the Board approves a lawful basis and a place for it. TODO(board): CRM of record, if any.
